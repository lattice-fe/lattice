<p align="center">A fast file explorer with full-text &amp; semantic search.</p>

<p align="center">
  Index any folder and find files by name, contents, or meaning, with rich in-app previews.<br>
  Fast where it counts, and a place you actually like being.
</p>

## Install

Download the latest installer from [**Releases**](https://github.com/lattice-fe/lattice/releases).

## Build from source

Requires Node 18+ and Rust 1.77+.

```bash
cd app && npm install && npm run tauri build   # or: npm run tauri dev
```
